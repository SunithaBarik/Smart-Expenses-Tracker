# 💰 Smart Expense Tracker

A simple Python project to track daily expenses and visualize spending with charts.

## 👩‍💻 Made By
Sunitha Barik

## ✨ Features
- Add daily expenses with item, amount and category
- View all expenses in a clean table
- Calculate total spending
- See category-wise spending (Food, Travel, Shopping)
- Pie Chart and Bar Chart for easy visualization

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## ▶️ How To Run
1. Open `expense-tracker.ipynb` in Jupyter Notebook
2. Run all cells one by one
3. Add your own expenses using:
```python
